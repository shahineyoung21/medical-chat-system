# صباح — معلومات صحية عامة بمصادر

**الحالة:** نموذج أولي عربي غير تشخيصي. تتصل واجهة Flutter بخادم FastAPI منفصل لاسترجاع معلومات عامة من MedlinePlus/NLM وعرض المصدر. لا يشخّص ولا يصف علاجًا أو جرعات، ولا يحفظ المحادثات.

لا تكتب معلومات شخصية أو تفاصيل صحية حقيقية في هذه النسخة. يُرسل سؤال عام إلى خادم التطبيق، لكن لا يُرسل نصه الخام إلى OpenAI؛ الخادم يمرر فقط موضوعًا عامًا مسموحًا ومقتطفات عامة من المصدر عند تفعيل المزود. الرسائل لا تُحفظ. لا تفعّل مزودًا خارجيًا إلا بعد مراجعة شروطه وسياسة الخصوصية المناسبة.

إذا ذكرت شكوى أو اشتباهًا بمرض، يعرض التطبيق توجيهًا لمراجعة طبيب ولا يرسل الشكوى للخادم. وإذا ظهرت كلمات طوارئ معروفة، يعرض رقم الإسعاف المصري 123 ورابط هيئة الإسعاف المصرية. هذه قواعد حتمية بسيطة وليست تقييمًا طبيًا أو نظامًا موثوقًا لفرز الطوارئ؛ لا تعتمد عليها بدل خدمات الطوارئ.

## تشغيل خادم التطوير

تحتاج Python 3.11 أو أحدث. من جذر المستودع:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements-dev.txt
uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

يفتح فحص الصحة على `http://127.0.0.1:8000/health`، وتكون واجهة المحادثة على `POST /api/chat`. الخادم لا يحفظ الرسائل. يتصل بواجهة MedlinePlus الرسمية بموضوعات عامة محدودة، ويخزّن نتيجة البحث العامة مؤقتًا في ذاكرة العملية لمدة 12 ساعة.

افتراضيًا يكون توليد الإجابات عبر OpenAI **متوقفًا**. لتفعيله في خادم تطوير خاص فقط، عيّن الإعدادات في بيئة الخادم ولا تضعها في Flutter أو GitHub:

```bash
export SABAH_LLM_ENABLED=true
export SABAH_OPENAI_API_KEY='ضع مفتاحًا خادميًا خاصًا هنا'
export SABAH_OPENAI_MODEL='اسم نموذج متاح لحسابك'
```

لا تستخدم المفتاح العام `OPENAI_API_KEY` في التطبيق، ولا تضع أي مفتاح في ملف Dart أو APK أو مستودع Git. لاختبار التكامل، استخدم بيانات اصطناعية فقط. حتى مع `store:false` قد تنطبق سجلات إساءة الاستخدام لدى المزود؛ لذلك هذه النسخة ليست معتمدة لإدخال شكاوى أو سجلات مرضى.

الموضوعات العربية المحدودة المدعومة حاليًا هي الربو والسكري وضغط الدم وفقر الدم والحساسية والكوليسترول والتهاب المفاصل ونزلات البرد والإنفلونزا. السؤال خارج القائمة لا يُرسل للنموذج ولا ينتج عنه جواب مُختلق.

## بناء APK وتجربته

يلزم نشر خادم HTTPS مناسب أولًا. ثم يُمرّر عنوانه عند بناء التطبيق، ولا يوضع فيه مفتاح النموذج:

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug --dart-define=SABAH_API_BASE_URL=https://عنوان-الخادم.example
```

أو أضف متغير GitHub Actions باسم `SABAH_API_BASE_URL` لتمرير عنوان الخادم إلى عملية البناء. لا تستخدم عنوان Sandbox المؤقت أو خادم تطوير مكشوفًا للإنتاج. إذا لم يُضبط العنوان، ستعرض الواجهة رسالة بأن الخادم غير مهيأ بدل رد ثابت مضلل.

ينتج APK الاختبار عادةً في:

```text
build/app/outputs/flutter-apk/app-debug.apk
```

بعد نقل الملف إلى الهاتف، يمكن فتحه من مدير الملفات أو تثبيته من Termux من دون رابط. انسخ APK إلى مجلد Download، ثم نفّذ:

```bash
termux-setup-storage
termux-open --view "$HOME/storage/shared/Download/app-debug.apk"
```

سيطلب Android السماح لـTermux بتثبيت تطبيقات غير معروفة؛ فعّل الإذن لهذا المصدر فقط ثم وافق على التثبيت. Termux لا ينقل APK من Sandbox ولا يتجاوز موافقة Android، لذلك يجب أن يكون الملف موجودًا على الهاتف أولًا (مثلًا عبر USB أو Bluetooth). نسخة debug للاختبار وليست إصدار متجر موقّعًا.

## المصادر والنطاق المصري

- MedlinePlus/NLM: خدمة بحث موثقة للموضوعات الصحية الإنجليزية؛ يَعرض التطبيق المصدر الأصلي ولا يوحي بأن NLM تؤيد التطبيق.
- وزارة الصحة والسكان المصرية: [mohp.gov.eg](https://www.mohp.gov.eg/) للإحالات والتوعية الرسمية.
- هيئة الإسعاف المصرية: [eao.gov.eg](https://eao.gov.eg/) وتعرض رقم 123.
- [مستشفيات جامعة القاهرة](https://cu.edu.eg/page.php?pg=contentFront/SubSectionData.php&SubSectionId=199) و[الخدمات الصحية بجامعة عين شمس](https://www.asu.edu.eg/healthcare) روابط مؤسسية للإحالة، وليست قاعدة معرفة علاجية.
- بوابة المجلس الصحي المصري والمستشفيات الجامعية تبقى مصادر للمراجعة والتعاون؛ لا ننسخ بروتوكولات مهنية أو جرعات إلى إجابات عامة دون إذن ومراجعة مختص.

ملف `QA-TestSet-LiveQA-Med-Qrels-2479-Answers.zip` في المستودع لم يُستخدم في الإجابات أو الاختبارات؛ لا يُدمج أي محتوى تشخيصي فيه قبل فحص المصدر والخصوصية وموافقة واضحة، ولا يُستخدم لجعل التطبيق يشخّص.

## التحقق

```bash
python3 -m pytest backend/tests
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

يتضمن GitHub Actions فحوص Python وFlutter وبناء APK تجريبيًا. لا يوقّع الإصدار للإنتاج ولا ينشره إلى Google Play. الإطلاق العام يتطلب مراجعة طبيب مصري، وسياسة خصوصية ومراجعة قانونية، واستضافة آمنة ومراقبة وحماية من إساءة الاستخدام.
